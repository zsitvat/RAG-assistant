# `.docs`

| Path | Contents |
| --- | --- |
| `plan/` | Planning reference: development workflow, idea/scope, technical design. |
| `tasks/` | Ordered, dependency-ranked implementation tasks (`01`–`14`), each with acceptance criteria. |
| `features/` | One doc per delivered feature: what it does, how it works, how to use it, key files. Kept in sync as the feature evolves. |
| `changes/` | Dated changelog entries for notable code changes only — not for documentation-only edits. |
| `sources/en/`, `sources/hu/` | Fictional company policy corpus (`.docx`). The English corpus is ingested for this PoC; the Hungarian mirror is not (see `plan/01-idea-plan.en.md`). |
| `*.pdf` (root) | The original assignment brief. |
